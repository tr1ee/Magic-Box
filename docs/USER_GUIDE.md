# Magic Box 操作手册

## 1. 安装与首次启动

### Windows

1. 从项目 Releases 下载 `windows-x64-basic.exe`，同时可下载同名 `.sha256` 文件核对完整性。
2. 运行安装程序，按提示安装到当前用户账户。没有 WebView2 时需要联网安装 Microsoft 运行时。
3. 从开始菜单或桌面打开 Magic Box。基础功能无需登录 Magic Box 账户，无需自行安装 Node.js 或 Python。
4. 在工具箱选择功能。每个工具顶部可以选择保存目录，建议先选择有足够空间且有写入权限的文件夹。

当前程序没有商业签名证书；请从本仓库下载并核对来源。卸载可通过 Windows 的“已安装的应用”完成。个人模型和数据与程序安装目录分开保存，卸载前请按需要备份。

### macOS

1. Apple Silicon 选择 `arm64` DMG，Intel Mac 选择 `x64` DMG，系统需 macOS 14 或以上。
2. 打开 DMG，将 MagicBox.app 拖到 Applications，然后从 Applications 启动。
3. 包采用临时签名，尚未经过 Apple 公证；如系统拦截，可在“系统设置 → 隐私与安全性”核对来源后允许打开。
4. 如果 Releases 没有适合的 DMG，可按 [Mac 说明](macos.md) 在本机编译。`Mac-Build.zip` 是构建工程，不能当 DMG 安装。

Mac 的语音克隆/训练自动安装器、Windows Edge 专用验证流程目前不可用；不要把这些平台限制误认为模型已损坏。

## 2. 种子下载

1. 进入 Torrents，选择保存目录。
2. 粘贴 Magnet 链接，或选择 `.torrent` 文件后点击添加。
3. 等待元数据出现，在文件列表中选择真正需要的文件。
4. 观察进度、速度和连接状态。取消文件选择只停止后续下载，不删除已有部分文件。

长时间没有速度时，先检查种子是否有在线做种者、网络是否允许 P2P，以及磁盘空间。应用不能让已经失效的种子自动恢复来源。

## 3. 图片下载

1. 进入 Images，粘贴网页 URL，点击 Scan images。
2. 通过文件名、类型、来源和序号筛选结果，勾选需要的图片。
3. 点击 Download selected。图片按网页标题归入保存目录下的子文件夹。
4. 在预览或历史中检查结果；失败条目可以重试。

普通静态 WebP 会转换为 PNG，动画 WebP 保留原格式。相同内容会去重，不会默认覆盖同名文件。动态、登录或受保护页面可能无法提取。

## 4. 视频下载

1. 进入 Videos，粘贴公开网页或直接视频链接。
2. 点击扫描，检查主视频、清晰度和预览，再开始下载。
3. 下载完成后从结果或历史打开保存目录。

部分站点需要用户手动完成验证；Windows 的支持流程可能使用本机浏览器。网站变化、登录权限、过期链接和 DRM 都可能导致失败。软件不提供绕过付费或访问控制的保证。

## 5. Format Factory 格式转换

1. 选择 Picture、Video、Audio 或 Document。
2. 选择输出目录，添加文件，设置输出格式与质量。
3. 开始转换并等待每个文件的实际状态更新。

源文件不会被修改。需要原件副本时选择 Keep original。支持图片转换、音视频转换、PDF 合并、图片/文本生成 PDF、PDF 页面导出和文档文本提取。DOCX 转 PDF 需要另外安装 LibreOffice。

## 6. 手机与电脑传文件

### 同一 Wi-Fi

1. 电脑与手机连接同一个可互访的 Wi-Fi，进入 File Transfer → Same Wi-Fi。
2. 点击 Start transfer room。
3. 检查二维码下方的“连接地址（二维码）”。优先使用 WLAN/Wi-Fi 地址；不能使用 `169.254.*` 或 `127.*`。
4. 手机使用系统相机扫描，在 Safari 或 Chrome 打开，输入电脑上的六位配对码。
5. 电脑发送：选择文件后点击 Share selected，手机页面点击 Download。
6. 手机发送：在手机页面选择文件，等待显示成功，再在电脑接收列表检查。

房间有效期 12 小时；点击 Stop room 会关闭房间。保存文件的位置显示在工具顶部和接收目录入口中。旧房间二维码在关闭或应用重启后会失效。

### 扫码后白屏或打不开

- 点击“刷新网络”并重新扫描当前二维码；有多个网卡时切换为手机所在 Wi-Fi 对应的地址。
- `169.254.*` 是自动分配的临时地址，新版已排除，看到它通常说明仍在使用旧版或旧二维码。
- 访客 Wi-Fi、校园/公司网络可能开启设备隔离；同一个 Wi-Fi 名称不保证设备可互访。
- Windows 弹出网络访问询问时，需要允许 Magic Box 的 Node.js 服务在私人网络通信。不建议关闭整个防火墙。
- 手机或电脑的 VPN、代理、扫码应用内置浏览器可能影响访问；可改用系统浏览器。
- “附近、无互联网”模式需要先打开电脑热点，让手机连接该热点，再开始或刷新房间。

当前不支持跨互联网远程房间。二维码里是局域网地址，不是可在外网访问的分享网址。

## 7. 可选本地 AI 与模型

1. 打开 Private Assistant → Models。
2. 查看模型用途、磁盘占用、内存需求和许可；确认后手动安装。
3. 下载完成并校验后激活模型，再使用聊天或资料索引功能。生成模型与嵌入模型用途不同，按页面提示配置。

推荐生成模型可能需要约 6.2 GB 下载空间及额外运行内存；机器资源较少时选择清单中的较小模型。安装包本身不带这些文件，也不带任何开发者训练的声音。

Windows 的 Voice Clone → Model Setup 提供另外的语音引擎安装流程，可能下载大量依赖和模型，GPU 支持取决于引擎与硬件。训练结果只保存在当前用户资料中，不会自动上传到本仓库。Mac 尚未提供这些引擎的自动安装。

只使用自己拥有使用权、且已取得说话者必要授权的音频。模型和第三方运行库的许可由相应项目决定。

## 8. 数据、升级与问题反馈

- Windows：通常为 `%LOCALAPPDATA%\MagicBox`。
- Mac：`~/Library/Application Support/MagicBox`，启动日志为其中的 `desktop.log`。
- 各工具的下载结果：以顶部选定目录为准。

升级前建议备份用户资料和重要下载文件；安装新程序通常不会覆盖用户模型目录。不要把个人数据复制到 Git 仓库或作为 Issue 附件。

反馈问题时附上操作系统、应用版本、最短复现步骤及错误文字。日志中请删除个人目录、Cookie、授权令牌、私人音频和其他敏感内容。
